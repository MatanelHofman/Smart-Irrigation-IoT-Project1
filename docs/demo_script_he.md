# סקריפט הדגמה - סרטון וידאו קצר

סקריפט מדויק להקלטת סרטון ההדגמה הקצר (`deliverables/Smart_Irrigation_Short_Demo.mp4`), וגם לקטע ההדגמה החיה בתוך הקלטת המצגת (שקף 11). משך כולל: כ-90-120 שניות.

## הכנה לפני ההקלטה

1. לוודא שהמתווך רץ: `docker compose up -d`.
2. להריץ את המערכת: `python run_project.py`.
3. לסדר את חלונות המערכת על המסך כך שרואים בו-זמנית (או לסירוגין): את ה-Dashboard, את חלון "Soil Moisture Knob", ואת חלון "Pump Relay".
4. למחוק נתונים ישנים לפני הרצה נקייה (למחוק את data/smart_irrigation.sqlite3 אם רוצים מסד ריק לגמרי).

## מה לומר ומה להראות, שלב אחרי שלב

**שלב 0 (5 שניות) - פתיחה**
להראות את חלון ה-Dashboard ריק/במצב התחלתי, ולומר: "זו מערכת ההשקיה החכמה שלנו, ה-Dashboard מראה את כל הנתונים בזמן אמת".

**שלב 1 (15 שניות) - מצב התחלתי, לחות 55%**
לפתוח את חלון "Soil Moisture Knob" ולוודא שהסליידר נמצא בסביבות 55%.
לומר: "לחות הקרקע כרגע 55 אחוז, לכן המצב הוא INFO והמשאבה כבויה" - להצביע על הבאנר הירוק ועל "Pump: OFF" ב-Dashboard.

**שלב 2 (20 שניות) - הורדה ל-30%, WARNING**
לגרור את הסליידר בחלון "Soil Moisture Knob" עד לערך של כ-30 אחוז.
לומר: "עכשיו אני מוריד את לחות הקרקע ל-30 אחוז" - לעבור לחלון ה-Dashboard ולהצביע על הבאנר שהפך לכתום עם הכיתוב WARNING, ועל "Pump: ON". אפשר גם להראות את חלון "Pump Relay" שמציג "Pump ON" ואת הסיבה "Soil is dry".

**שלב 3 (15 שניות) - הורדה ל-15%, ALARM**
להמשיך לגרור את הסליידר עד לכ-15 אחוז.
לומר: "אם הקרקע ממשיכה להתייבש, ל-15 אחוז למשל, המערכת מעלה את רמת ההתראה ל-ALARM" - להצביע על הבאנר האדום.

**שלב 4 (15 שניות) - העלאה בחזרה ל-50%, INFO**
לגרור את הסליידר בחזרה לכ-50 אחוז.
לומר: "וברגע שהלחות חוזרת מעל 45 אחוז, המצב חוזר ל-INFO והמשאבה כבית מעצמה, באופן אוטומטי לגמרי".

**שלב 5 (25 שניות) - מצב ידני**
לפתוח את חלון "Control Button", ללחוץ על "Switch to MANUAL".
לומר: "עכשיו אני עובר למצב ידני" - ללחוץ על "Pump ON" ולהראות שהממסר וה-Dashboard מציגים מיד "Pump: ON" ו-"Mode: MANUAL". ללחוץ על "Pump OFF" ולהראות את השינוי בחזרה.

**שלב 6 (10-15 שניות) - הצצה למסד הנתונים**
אפשר לפתוח טרמינל ולהריץ שאילתה קצרה שמראה שהנתונים באמת נשמרים:

```bash
python3 -c "
import sqlite3
conn = sqlite3.connect('data/smart_irrigation.sqlite3')
for row in conn.execute('SELECT timestamp, state, mode, reason FROM actuator_states ORDER BY id DESC LIMIT 5'):
    print(row)
"
```

לומר: "כל שינוי במשאבה נשמר גם בטבלת actuator_states במסד ה-SQLite, אז אפשר לראות את כל ההיסטוריה".

**סיום** - לחזור למסך ה-Dashboard ולומר משפט סיום קצר, למשל: "זו המערכת שלנו - תודה על הצפייה".

## לגבי הסרטון המצורף

הקובץ `deliverables/Smart_Irrigation_Short_Demo.mp4` הוא הקלטת מסך אמיתית של המערכת בפעולה (ללא קריינות קולית) - כל השלבים שמופיעים בו (WARNING, ALARM, חזרה ל-INFO, מעבר למצב ידני והדלקה/כיבוי של המשאבה) הם תוצאה של הרצה אמיתית של הקוד, ולא הדמיה. אם רוצים גרסה עם קריינות בעברית, אפשר להשתמש בסרטון הזה כבסיס ולהוסיף עליו שכבת קול לפי השלבים המתוארים למעלה.

## הערות טכניות

- כל שינוי בסליידר משודר מיד דרך MQTT, כך שאין צורך להמתין - השינוי בממשקים אמור להופיע תוך פחות משנייה.
- אם רוצים תזמון מדויק וחוזר על עצמו לבדיקות, אפשר להריץ את `python demo_scenario.py` שמשדר את אותם הערכים אוטומטית - אך לסרטון עצמו מומלץ להדגים ידנית עם הסליידר האמיתי, כדי שיהיה ברור שזו הדגמה חיה.
- קובץ הסרטון הסופי, אם נוצר בפועל, נשמר בנתיב `deliverables/Smart_Irrigation_Short_Demo.mp4`. אם לא הוקלט סרטון אמיתי, יש להשאיר את הסימון `[ADD_DEMO_VIDEO_LINK]` במצגת ובקובץ `deliverables/MISSING_LINKS.txt`, ולא ליצור סרטון מזויף.
